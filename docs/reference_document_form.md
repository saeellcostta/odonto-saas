# Estrutura do Formulário de Atestado - Site de Referência

## Campos do Formulário:
1. **Profissional** - Select dropdown para escolher o dentista
2. **Tipo de Atestado** - Radio buttons:
   - Atestado de dias
   - Presença na consulta
3. **Data** - Campo de data (padrão: data atual)
4. **Quantidade de dias** - Campo numérico (quando tipo = dias)
5. **Incluir CID** - Checkbox com texto "(requer autorização do paciente)"

## Botões:
- Cancelar
- Salvar e Imprimir

## Observações:
- O formulário não tem campos de assinatura visíveis no modal
- As assinaturas aparecem apenas no PDF gerado
- O PDF inclui linhas de assinatura para profissional e paciente
